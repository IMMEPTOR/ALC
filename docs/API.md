# ALC — Документация REST API

Базовый URL: `http://localhost:4000/api`

Все защищённые эндпоинты требуют заголовок `Authorization: Bearer <token>`.

---

## 1. Аутентификация (`/api/auth`)

| Метод | Роут | Заголовок | Описание | Принимает (Body / Params) | Возвращает (200/201) | Доп. статус-коды |
|-------|------|-----------|----------|---------------------------|----------------------|------------------|
| POST | `/api/auth/login` | Вход в систему | Аутентифицирует пользователя по логину и паролю, создаёт JWT-сессию | `{ username: string, password: string }` | `{ token: string, user: { id, username, role, permissions[] } }` | `400` — не указаны username/password; `401` — неверные учётные данные; `403` — аккаунт деактивирован |
| GET | `/api/auth/me` | Текущий пользователь | Возвращает данные авторизованного пользователя по токену | — (Bearer token) | `{ user: { id, username, role } }` | `401` — не авторизован |
| POST | `/api/auth/logout` | Выход из системы | Удаляет серверную сессию (инвалидирует токен) | — (Bearer token) | `{ message: "Выход выполнен" }` | `401` — не авторизован |

## 2. Пользователи (`/api/users`) — только admin

| Метод | Роут | Заголовок | Описание | Принимает (Body / Params) | Возвращает (200/201) | Доп. статус-коды |
|-------|------|-----------|----------|---------------------------|----------------------|------------------|
| GET | `/api/users` | Список пользователей | Получает список всех пользователей (без пароля) с их ролями | — | `User[]` (массив объектов с populated role_id) | `401`, `403` |
| GET | `/api/users/:id` | Пользователь по ID | Получает одного пользователя по его идентификатору | `id` — path param | `User` объект | `401`, `403`, `404` — пользователь не найден |
| POST | `/api/users` | Создание пользователя | Создаёт нового пользователя с указанной ролью | `{ username: string, password: string, role_name: string }` | `{ id: string, username: string }` | `400` — обязательные поля не заполнены; `409` — пользователь уже существует; `401`, `403` |
| PUT | `/api/users/:id` | Обновление пользователя | Обновляет данные пользователя (роль, активность, пароль) | `{ is_active?: boolean, role_name?: string, password?: string }` | `User` обновлённый объект | `400` — роль не найдена; `404`; `401`, `403` |
| DELETE | `/api/users/:id` | Удаление пользователя | Удаляет пользователя из системы | `id` — path param | `{ message: "Пользователь удален" }` | `404`; `401`, `403` |

## WebSocket (Socket.io)

URL подключения: `ws://localhost:4000`

При подключении клиент должен передать `token` в `auth`:
```js
io('ws://localhost:4000', { auth: { token: '<JWT>' } })
```

### События (Server → Client)

| Событие | Описание | Payload |
|---------|----------|---------|
| `telemetry:new` | Новая запись телеметрии | `TelemetryRecord` |
| `alert:new` | Новый аларм | `Alert` |
| `node:statusChanged` | Изменение статуса узла | `{ nodeId: string, status: string }` |
| `command:statusChanged` | Изменение статуса команды | `Command` |

### События (Client → Server)

| Событие | Описание | Payload |
|---------|----------|---------|
| `subscribe:node` | Подписаться на обновления узла | `nodeId: string` |
| `unsubscribe:node` | Отписаться от обновлений узла | `nodeId: string` |

## Роли и доступ

| Роль | Описание | Доступные действия |
|------|----------|-------------------|
| `admin` | Администратор | Полный доступ: CRUD пользователей, площадок, линий, узлов, команд, алармов |
| `engineer` | Инженер | Чтение всех данных, управление узлами, создание команд, подтверждение и разрешение алармов |
| `operator` | Оператор | Чтение данных, создание команд, подтверждение алармов |
| `viewer` | Наблюдатель | Только чтение данных мониторинга |

## Модели данных

### Parameter (вложен в TechNode)
```json
{
  "param_id": "string",
  "name": "string",
  "unit": "string",
  "min_value": "number",
  "max_value": "number",
  "update_interval_sec": "number"
}
```

### Общие коды ошибок
| Код | Описание |
|-----|----------|
| `400` | Некорректный запрос (отсутствуют обязательные поля) |
| `401` | Не авторизован (отсутствует или невалидный токен) |
| `403` | Доступ запрещён (недостаточно прав роли) |
| `404` | Ресурс не найден |
| `409` | Конфликт (дубликат) |
| `500` | Внутренняя ошибка сервера |
